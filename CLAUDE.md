# Working in this repo

- **Merge to `main` yourself, always.** Lola's rule from 20 November 2026. Work on a branch, open the
  pull request, then merge it straight away - do not wait for Lola.
- **Merging to `main` puts it live.** `.github/workflows/deploy.yml` uploads `main` to the website by
  FTP within about a minute. Check the Actions tab goes green after each merge.
- **How to report to Lola:** point form, the steps she has to take, plain NZ English, metric.
