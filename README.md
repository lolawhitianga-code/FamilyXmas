# FamilyXmas

Christmas at Bateau Bay 2026 - the family web app (who's coming, plan, meals, games, Secret Santa, photos).

- Live at https://mybaliholiday.kiwi/xmas/
- All the site files are in `xmas/`. Upload that folder as-is to the `xmas` folder on the web host.
- Data is saved in the same Firebase project as the other trips, in collections starting `xmas_`.
